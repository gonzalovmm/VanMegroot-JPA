# Persistencia de Datos con JPA (Proyecto Académico)

Proyecto académico desarrollado para la materia Desarrollo de Software  
(Ingeniería en Sistemas – UTN Facultad Regional Mendoza).

Este repositorio se publica como parte del recorrido formativo y tiene como objetivo demostrar el uso básico de JPA para la persistencia de entidades y manejo de transacciones.

---

## Descripción

El proyecto implementa un modelo de dominio simple utilizando JPA, incluyendo entidades relacionadas como facturas, clientes, artículos y categorías.

Se practican conceptos fundamentales de persistencia, relaciones entre entidades y control transaccional.

---

## Funcionalidades implementadas

- Persistencia de entidades mediante JPA.
- Manejo de relaciones entre entidades.
- Creación de facturas con múltiples artículos.
- Cálculo del total de una factura.
- Control de transacciones con commit y rollback.

---

## Tecnologías utilizadas

- Java
- JPA
- Hibernate
- Base de datos relacional

---

## Estado del proyecto

Proyecto académico formativo.  
Orientado a la comprensión de fundamentos de persistencia con JPA.
